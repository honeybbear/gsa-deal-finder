How the method works

  1. Pull live lots from GSA Auctions' public trending feed.
  2. Keep only lots with a specific model identifier (year/make/model or brand+model).
  3. Find a public resale reference from search-result snippets (value guides, dealer and auction listings). A published value range uses its low end; otherwise the median of snippet figures from at least two domains.
  4. Flag a DEAL only when bid + shipping allowance is under 50% of that reference. GSA lists no buyer's premium; verify on the lot page before bidding.
  5. Prefer local pickup where possible — shipping is the fastest margin killer.

Honest limitations — read before acting

  • Coverage is partial. GSA's full lot search requires a logged-in session token; this checker does not create accounts, so it scans the public trending feed (10 lots per run) against 695 total lots across 21 categories. Most inventory is NOT scanned. Browse the public GSA search yourself for the rest.
  • eBay sold prices are unavailable to automation (eBay returns 403 to bots), so resale references come from public search snippets — asking prices and value guides, not completed sales. Treat every margin as rough, and re-verify a specific lot's resale value before bidding.
  • References move between runs as search results change. A deal flagged today can disappear tomorrow.
  • As-is condition. Surplus is sold as-is, where-is. Inspection is strongly recommended; condition problems can erase the whole margin.
  • Shipping allowances are planning numbers, not quotes. Heavy items can cost far more to move than the allowance.
  • No guaranteed profit. Bids rise, items disappoint, resale markets move. This page is educational only, not financial advice, and it never buys anything on your behalf.
